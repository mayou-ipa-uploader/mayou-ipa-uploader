开始使用

第一次使用时，先点击右上角头像完成登录。登录后可以创建浏览器环境、使用相似度检测、配置代理以及上传 IPA。

1. 登录点击右上角头像，使用微信扫码登录。授权完成后回到应用即可。
2. 选择功能左侧菜单进入浏览器窗口、检测相似度、代理 IP 或 IPA 包上传。
3. 检查状态右上角头像显示当前账号；正式包默认连接正式服务器。
浏览器环境数据和登录状态会保存在当前电脑。重复点击应用图标只会复用同一个窗口。

浏览器环境

每个浏览器环境拥有独立的指纹、Cookie 和缓存。建议按账号或业务分别创建环境，避免多个账号共用同一环境。

  1. 进入“浏览器窗口”，点击“创建窗口”。
  2. 填写窗口名称、备注和首页地址；需要代理时在代理字段选择已配置的代理。
  3. 根据业务需要设置语言、时区、地理位置和 WebRTC 等指纹参数。
  4. 保存后点击“打开”，关闭浏览器窗口不会删除环境。

浏览器窗口：搜索、刷新、创建并打开环境。

代理 IP

先在“代理 IP”中添加代理，再回到浏览器环境绑定。代理检测通过后，环境打开时会使用对应出口 IP。

  1. 点击“添加代理”，选择代理类型并填写地址、端口及认证信息。
  2. 保存后点击“检测”确认代理可用。
  3. 批量操作可使用“批量代理检测”、导入和导出功能。
  4. 在创建或编辑浏览器环境时选择代理，保存配置。

代理 IP：添加、检测和管理代理。

相似度检测

相似度检测使用线上检测服务 similarity.msykeji.com。上传参考 IPA 和待检测 IPA 后，系统会识别语言、Mach-O、资源和相同文件。

  1. 进入“检测相似度”。
  2. 选择参考 IPA 和新 IPA；也可以直接拖拽文件到对应区域。
  3. 选择检测模式和检测项目后开始检测。
  4. 检测完成后查看结果，并在“检测卡”中购买或查看剩余次数。

相似度检测：上传两个 IPA 文件并选择检测模式。

IPA 包上传

IPA 上传使用软件内置安全上传通道。系统会根据 IPA 的 Bundle ID 自动匹配上传团队；Apple ID 需要使用 App 专用密码。

  1. 选择 IPA 文件。
  2. 填写 Apple ID 和 App 专用密码，不要填写 Apple ID 登录密码。
  3. 选择本地直连，或选择浏览器环境代理。
  4. 点击“开始上传”，在右侧日志查看进度和错误信息。
App 专用密码在 Apple 账户的“登录和安全”中创建。上传失败时先检查账号权限、Provider、Bundle ID 和网络代理。

IPA 包上传：配置文件、账号、网络方式和上传日志。

开发者账户管理

开发者账户用于管理 Apple 开发者账号和证书。添加账户时按页面要求完成登录授权；证书下载后可在对应功能中使用。

开发者账户管理：绑定、查看和管理 Apple 开发者账户。

常见问题

扫码授权成功后页面没有变化

先确认手机提示授权成功，再等待 3 到 5 秒。若仍未变化，关闭登录页后重新打开二维码；不要重复启动应用。

浏览器启动了两个窗口

当前版本使用单实例机制。先退出旧版本，再从应用程序中打开唯一的“码友浏览器”。

相似度检测二维码不显示

确认已部署最新后台包并重启宝塔项目，再刷新检测卡页面。可用浏览器开发者网络记录确认 `/api/pay/create` 返回 200。

IPA 上传失败怎么办

检查 IPA 是否完整、Bundle ID 是否正确、Apple ID 是否有权限，并确认填写的是 App 专用密码。
