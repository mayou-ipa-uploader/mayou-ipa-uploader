# 码友证书管理 v0.1.388 · Mayou IPA Uploader

## 版本介绍

面向 iOS 开发者和应用上架团队，集中处理 IPA 上传、证书与描述文件管理、App Store Connect 应用管理及 TestFlight 内测。

## 主要功能

- 上传已签名的 IPA，查看苹果处理进度与错误。
- 按上架、测试场景准备证书和描述文件，下载已同步签名材料。
- 查看应用版本、Bundle ID、证书、描述文件和测试设备。
- 查看 TestFlight 构建，管理测试群组、测试员及测试信息。
- 按 App 连接审核专员获取协助。
